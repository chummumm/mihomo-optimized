# 内核版本摘要

这里是 GitHub Release 正文的唯一摘要来源，按版本倒序排列。每次人工递增
`PROJECT_VERSION` 时，在顶部新增对应的 `## X.Y.Z`，只写本版变化和必要的升级提醒。
不要复制旧版记录、通用配置教程或整段测试日志。详细机制和历史迁移保留在
[发行与安装说明](releases.md)及各功能文档中。

`scripts/release-notes.py` 精确提取当前版本；版本缺失、重复、顺序错误或构建身份不符
会拒绝发布。上游同步由现有同步脚本写入准确的上游版本摘要，随后仍通过全部发布检查。
下面的历史记录按各版标签对应的源码核对，未发布独立内核的 `1.0.18` 不列入记录。

## 1.0.38

### 本次更新

- 修复旧版 UOT 把封装头计入写入长度的问题，避免共享 UDP DNS 把完整发送误判为 `short write`。
- 覆盖 Shadowsocks UDP-over-TCP 和 TUIC UDP-over-Stream 的旧版路径；真实短写和底层错误仍正常报告。
- 增加报文边界、共享与独立 DNS 的回归验证。此次修复针对 issue #72 中已确认的 UOT 缺陷，实机完整故障仍需复测。

## 1.0.37

### 本次更新

- 普通 Windows 内核恢复上游 TUN 创建和复用方式，修复替换第三方客户端内核时的同名网卡冲突（#92）。
- 自家桌面的 `desktop-managed` 模式继续使用专属设备管理，并补齐旧产品 GUID 残留的身份核验与迁移。
- 修复 AnyTLS 服务端首包缓存读取与关闭之间的竞态和认证失败时的缓存引用释放。

### 升级注意

替换第三方宿主的内核前，先由原宿主停止旧内核；不按网卡名称直接删除或接管身份不明的设备。

## 1.0.36

### 本次更新

- 修复重启内核时 PnP 记录已移除、接口表仍保留旧行导致的 `native_identity_missing`。
- 对身份匹配的本产品设备交由 Windows 原生创建流程处理移除过渡；保留活跃拥有者保护和创建后身份核验。

### 升级注意

桌面 0.2.11 可独立更新本版内核取得修复；桌面 0.2.12 完整安装包同时提供配套客户端验证与组件。

## 1.0.35

### 本次更新

- 受管内核直接绑定系统分配的控制端口，再把实际地址交给桌面，消除先探测再绑定的端口竞争。
- 控制端口或启动记录发布失败时清理已创建资源；同一实例重载保留控制监听器。

### 升级注意

完整启用新启动交接需要桌面 0.2.11 或更新版；旧客户端独立更新内核后仍沿用原有启动方式。

## 1.0.34

### 本次更新

- 修复 Windows TUN 关闭后重新创建的生命周期处理，已核实的本产品设备交由 Wintun 原生创建协调。
- 按实际 `NetCfgInstanceId` 核对设备，修正 Wintun 清理调用，保留外部同名设备保护和失败清理。
- 修正启动资源与 Debian 迁移测试的隔离问题，保留真实超时及资源校验。

### 升级注意

配套的历史失败提示清理、备用名恢复和 TUN 快速切换改动需要安装桌面 0.2.11；独立更新内核不更新桌面组件。

## 1.0.33

### 本次更新

- 修正 Windows SOCKS UDP 回归测试的端口分配，避免把 TCP 随机端口误用于 UDP。
- 稳定资源下载取消测试，macOS 发布检查改用可用的 Intel runner，保留既有检查要求。
- 本版调整测试和构建环境，不改变生产网络行为。

## 1.0.32

### 本次更新

- 受管内核启动及重载成功后立即采样 TUN 健康状态，避免首次桌面查询才启动采样。
- TUN 配置未变化时保留真实健康观察及时间戳；设备变更仍立即使旧结果失效。

## 1.0.31

### 本次更新

- 合入上游 Mihomo v1.19.34，包含该稳定版的协议与连接处理更新。
- 保留本项目 EasyTier 目标路由等待、LAN 预连接和本地 TUN 补丁。

## 1.0.30

### 本次更新

- 为同步上游 v1.19.34 补齐 EasyTier 报文队列清理，并保留本项目的实例管理与路由等待。
- 更新本地 sing-tun 到 v0.4.29 基线，保留 Windows 所有权和 TCP 延迟握手补丁。
- 增加依赖基线一致性及精确冲突匹配检查；本版上游基线仍为 v1.19.33，完整同步在 1.0.31 交付。

## 1.0.29

### 本次更新

- DNS 上游独立选路统一使用 `dns.respect-rules`，移除额外的顶层开关（#74）。
- 自动 DNS 分流支持 `nameserver-policy` 和 `direct-nameserver-follow-policy`，保留显式出口与私有解析池隔离（#76）。
- 接通多类 TCP 入站的建连成功/失败反馈，保留正常半关闭与各协议原有语义。

### 升级注意

删除 `dns-upstream-rule-routing` 后完整重载。已启用 `dns-rule-routing`、原本希望 DNS 继承业务出口的配置，应明确设 `dns.respect-rules: false`；`true` 表示自动 DNS 上游按自身地址选路。之前被忽略的无效 policy/provider 引用也需要修正。

## 1.0.28

### 本次更新

- 修复 Windows 强制结束内核后，本产品 TUN 残留导致后续持续启动失败的问题。
- 仅对身份可确认且 Windows 明确判定不在场的本产品实例重新创建；仍保护活跃和外部设备。

### 升级注意

配套桌面为 0.2.6。旧通用 GUID 或身份不明的同名设备不自动接管，应先停止原拥有者，或选择未占用的 `tun.device` 名称。

## 1.0.27

### 本次更新

- Windows 创建 TUN 前增加同名接口检查，避免原生创建把已有设备改名。
- 旧设备短暂移除阶段只读等待；仍有冲突或无法确认身份时返回错误，不打开接管外部设备。

### 升级注意

本版尚不处理所有强制退出残留；本产品已离场实例的恢复在 1.0.28 进一步修复。

## 1.0.26

### 本次更新

- Wi-Fi 切换时优先保留健康内核与 TUN，对确认缺失的自有地址和路由执行局部修复。
- 配置和健康查询读取快照，避免等待网卡恢复导致桌面误判内核停止。
- 恢复任务增加可查询结果和取消能力，修正部分创建失败后的资源清理。

### 升级注意

完整的桌面状态、心跳与停止响应改进需要桌面 0.2.6 安装包；源地址变化仍可能使已有连接断开。

## 1.0.25

### 本次更新

- 新增 `dns-upstream-rule-routing`，让自动 DNS 上游按解析器自身域名/IP 独立匹配规则（#69）。
- 覆盖 UDP、TCP、DoT、DoH、HTTP/3 和 DoQ，保留显式 DNS 出口优先级及业务解析池选择。
- 固定实际选中的解析器地址，保持 TLS SNI、证书验证和缓存作用域隔离。

### 升级注意

新开关默认关闭，修改后需完整重载；该字段从 1.0.29 起改由 `dns.respect-rules` 统一表达，跨版本升级请按对应迁移说明调整。

## 1.0.24

### 本次更新

- 修复启用 `proxy-force-ip` 时，DoH 等上游域名被错误交回业务 DNS，导致解析或节点测速超时的问题（#67）。
- DNS 上游使用独立引导解析，保留代理地址族限制、TLS SNI、证书验证和 HTTP Host。

## 1.0.23

### 本次更新

- 对实际 RFC1918/ULA 业务目标进行后台 LAN 通道准备，覆盖 EasyTier、WireGuard/AmneziaWG、Tailscale、ZeroTier 和 OpenVPN。
- 新增可选 `proxy-force-ip`、节点地址族约束与 DNS 答案地址族策略，保留域名规则、日志和 normal 模式（#61）。
- 为 Windows 桌面提供动态 TUN 健康与恢复接口，保护已有健康实例。

### 升级注意

回退 1.0.22 的请求内延长预算，普通业务恢复 5 秒期限；未知冷目标首次请求仍可能超时。桌面睡眠恢复配套改动需要桌面 0.2.5。

## 1.0.22

### 本次更新

- EasyTier 首次拨号等待实际目标路由和下一跳就绪，避免组网尚未完成就耗尽连接期限。
- 实际 EasyTier 请求允许最多 15 秒准备、再加 5 秒 TCP 建连，整次上限 20 秒；普通 TCP 仍为 5 秒。
- 并发请求共享初始化，修正迟到通知、取消和关闭期间的处理。

### 升级注意

调用方更短的期限仍然生效。该延长预算仅属于本版行为，1.0.23 改为 LAN 后台准备并恢复普通期限。

## 1.0.21

### 本次更新

- 合入上游 Mihomo v1.19.33，包括 FakeIP 重载状态、DoH 拨号取消和 TUN DNS 模式等更新。
- 保留本项目 DNS 优选、资源引导和独立更新机制。

## 1.0.20

### 本次更新

- `resource-bootstrap.proxy` 支持 select、fallback、url-test、load-balance、GLOBAL 及嵌套代理组。
- 复用现有选择和本地订阅缓存；幂等下载可按组策略避开失败路径，所有操作共用既定预算。
- provider 显式出口同样可独立引导，不依赖旧内核或系统代理预先运行。

## 1.0.19

### 本次更新

- 新增 `resource-bootstrap`，在启动下载规则、Geo 数据及 HTTP provider 时使用已有代理节点或缓存订阅。
- 启动资源下载共享总预算，保留显式出口、缓存优先和内容校验，失败不会静默改为直连。
- 收录受管桌面的内核生命周期与认证就绪接口。

### 升级注意

配套桌面启动预算改进需要桌面 0.1.4。版本从公开 1.0.17 跳到 1.0.19，以避开早期桌面内置的 1.0.18。

## 1.0.17

### 本次更新

- 连接快照增加单调采样时间和序号，避免网络或浏览器延迟造成流量速率虚高。
- 保持原有累计流量和连接字段兼容，配套面板 0.4.11 使用内核采样时间并改善页面恢复显示。

## 1.0.16

### 本次更新

- 多上游查询优先正常答复和 NXDOMAIN，避免快速返回的错误码抢先结束解析。
- 普通竞速与三种 DIRECT 响应策略保持统一，错误兜底仍遵守原有解析池、过滤和总预算。
- 兜底答案按原始接收时间老化 TTL，不因等待其他上游延长寿命。

## 1.0.15

### 本次更新

- HTTPS 记录支持 `ipv4hint`/`ipv6hint` 测速，每条服务记录保留本轮最快的有效提示。
- 保留 ECH、ALPN、端口及服务绑定；不同记录不混合，无法测量时保留原提示。
- 复用现有 DIRECT 测速预算和缓存，不新增必填配置。

## 1.0.14

### 本次更新

- DNS 统计排除节点和解析器的基础引导查询，继续保留真实业务及后台解析统计。
- 查询详情保留实际回答来源与出口，区分缓存命中和真实上游交换。
- 过期预取间隔缺省值改为 28800 秒；显式 `0` 仍按过期保留时间推导。

## 1.0.13

### 本次更新

- 省略 `speed-check-mode` 时使用自动测速，按 TCP 443、TCP 80、ping 调度，保持 DIRECT 范围和共享预算。
- 新鲜缓存预取统一为剩余 TTL 的 50%，保留有限热度、过期重查及按需刷新。

### 升级注意

已启用 `dns-rule-routing` 且省略测法时会开始自动测速；关闭须显式留空或设 `null`、`""`、`[]`。旧 `speed-check-mode: none` 改为空值，旧 `transparent-proxy.tcp/udp: off` 改为留空、`null` 或 `""`，并删除 `prefetch-mode`。省略协议字段仍启用其默认后端，不能用省略代替关闭。

## 1.0.12

### 本次更新

- DIRECT 定时预取从首次成功查询激活，按剩余 TTL 约 80% 刷新，并限制热度、队列和共享并发。
- Linux 增加真实 TCP SYN 测速，双栈优选复用有效缓存，减少额外查询。
- 补齐多地址数量、提前答案 TTL、HTTPS 提示及负缓存边界。

### 升级注意

显式 `tcp-syn` 需要受支持的平台与原始套接字权限。本版仍使用 `prefetch-mode`；升级到 1.0.13 时需按其说明删除该字段。

## 1.0.11

### 本次更新

- DIRECT DNS 可返回多个接近最快的地址，新增数量、TTL 和查询类型过滤设置。
- DIRECT 尊重客户端已经指定的真实目标 IP，域名仍用于规则判断。
- PR 改为代表平台纯编译检查，合并后完整打包一次并复用同次运行产物发布。

### 升级注意

配置键严格使用 `force-no-CNAME`、`force-AAAA-SOA`、`force-qtype-SOA`、`dualstack-ip-allow-force-AAAA`；旧大小写别名不再接受，升级前请改正并校验配置。

## 1.0.10

### 本次更新

- 同一 DNS 上游和实际出口的统计在普通重载后保持连续，节点配置改变仍分别统计。
- 裸内核更新增加版本/平台预检、Unix 执行权限修复和低存储占用保护。
- 配套面板 0.4.8 可显示内核、面板、Geo 数据和规则订阅的下一次自动检查时间。

### 升级注意

已被旧更新器路径或权限问题卡住的设备，首次进入本版可能仍需手动替换一次二进制。

## 1.0.9

### 本次更新

- 修复 TUN 接口重建期间逐接口 sysctl 暂时消失导致的错误失败。
- 保留黑洞保护，真实权限、只读文件系统及全局配置错误仍正常报告。
- 故障恢复后输出一次真实后端状态，健康期间不重复刷日志。

## 1.0.8

### 本次更新

- 普通 PR 使用 7 个代表打包目标，高风险改动保留完整 37 目标检查，正式发布仍构建全平台。
- 本版优化构建流程，不改变生产网络行为；1.0.11 后续进一步分离检查与正式打包。

## 1.0.7

### 本次更新

- 透明代理增加 TCP REDIRECT，TCP/UDP 可分别设置旁路端口。
- 合并重复 RA 和无关网络事件，减少不必要的路由同步与 DNS 连接重置。
- 原生安装包改用 `mihomo` 服务用户，并处理默认数据目录和二进制归属。

### 升级注意

服务用户迁移需要升级一次原生安装包，再执行 `systemctl daemon-reload` 和重启服务；内核自更新不会迁移账号或目录归属。手动替换二进制须准备服务用户和权限，或明确配置 `local.bypass-users`。旧 `bypass-udp-ports` 与新 `bypass-ports` 不可混用。

## 1.0.6

### 本次更新

- 新增默认关闭的 Linux 透明代理托管，TCP/UDP 可独立选择后端与本机/网关范围。
- 按系统网络事件维护规则和路由，TUN 重建前建立黑洞保护，避免流量意外落入普通路由。
- 正常停止清理本进程自有规则与路由，保留外部资源。

### 升级注意

启用托管时，请移除旧手写捕获规则、systemd 路由命令与动态前缀 cron；托管会接替运行态的 `auto-route`/`auto-redirect`。本版用 `off` 关闭协议，升级到 1.0.13 后须改为空值。

## 1.0.5

### 本次更新

- Geo 数据自动调度跟随完整配置重载的开关和间隔变化。
- 初次缺文件或下载失败不再永久停止后续检查，仅处理当前配置实际使用的数据库。
- 校验更新间隔为有效整数小时，避免计时溢出。

## 1.0.4

### 本次更新

- 统一更新入口检查并更新配置中的规则、Geo 数据、面板和内核，支持查询实际任务进度。
- 内核最后替换并重启，其他资源沿用原有来源与校验。
- DNS 筛选总数与分页游标由同一次后端查询返回，减少页码和计数错位。

## 1.0.3

### 本次更新

- 支持 FakeIP 与 `dns-rule-routing` 同时使用，hosts/FakeIP 保持优先，真实解析再进入 DNS 规则选路。
- 合成 FakeIP 不访问上游或执行 IP 测速；相关域名拒绝在后续业务连接阶段生效。
- 移除已停用的独立 DNS 端口配置与 API 处理。

## 1.0.2

### 本次更新

- 配置编辑前检查实际写入能力，不可安全写入的文件显示为只读。
- 保存期间权限变化时保留草稿并明确报错，配套面板 0.4.4 改善移动端编辑体验。

## 1.0.1

### 本次更新

- 已开启的内核和面板自动更新策略，在启动或重启后立即后台检查一次。
- 从关闭切换为开启时立即检查；相同策略重载保留原计时，间隔变化重新安排。
- 管理的面板目录为空时自动初始化，即使周期更新未开启。

## 1.0.0

### 本次更新

- 启用独立 `mihomo-optimized-vX.Y.Z` 版本系列，内核版本与上游基线分别记录。
- 提供固定标签、校验和与平台匹配的内核/面板自动更新；默认不开启周期更新。
- UDP、TCP、DoT DNS 复用稳定出口的连接，单个查询取消不影响其他查询。
- 原生包统一为 `mihomo-optimized`，保留二进制、配置目录和服务路径。

### 升级注意

`v1.19.32-optimized-N` 及更早内核无法解析新版本格式，需要手动安装一次新系列。新包替换旧包时保留用户配置；安装包不会自动启动或重启服务。
