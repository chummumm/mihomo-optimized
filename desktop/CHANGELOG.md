# Windows 桌面版更新记录

每个版本只记录该版变化和必要的升级提示。安装、配置与验证方式见 [使用指南](README.zh-CN.md)。历史记录中的行为与限制以对应版本为准。

维护发布时新增一个与 `desktop/app.json` 一致的 `## X.Y.Z` 段落；发布脚本按 `build-info.json` 的桌面版本精确提取，不复制其他版本。随包内核、网页面板和下载地址由构建信息生成，不在此重复维护。

## 0.2.12

- 修复点击“重启内核”后，旧 TUN 的 PnP 记录已移除、接口表仍有残留时误报 `native_identity_missing` 的问题。
- 符合本产品身份的残留记录交由 Windows 原生创建流程处理；外部同名设备、身份冲突和查询错误仍会拒绝。
- 增加连续 20 次完整重启及真实 TUN 转发验收。

### 升级提示

0.2.11 用户也可独立更新内核至 1.0.36 或更新版本取得此项修复；从更早桌面版本升级须使用完整安装包，同步更新宿主与服务协议 v5。

## 0.2.11

- 修复 Windows TUN 重新创建时的设备归属判断，取消 TUN 失败后自动切换备用网卡名的行为；显式设备名继续生效。
- 区分当前运行状态和上次操作失败，避免旧 TUN 报错长期残留。
- 单独开关 TUN 时局部应用并回读配置，减少整份配置重载；失败仍回滚。
- 由内核直接分配控制端口并交接实际地址，消除探测后再次绑定的竞争。
- 修复独立内核更新收尾状态被心跳覆盖的问题。

### 升级提示

本版使用宿主与服务协议 v5，必须使用完整安装包；独立更新内核无法升级旧界面、宿主和服务。

## 0.2.10

- 修复后台已恢复健康但界面仍保留旧错误提示的问题，区分健康采样中、真实异常和操作失败。
- 模式、局域网开关、日志等级和端口改为轻量更新并回读确认。
- 已安装服务的普通模式与 TUN 由同一服务管理，开关 TUN 不再每次重启整个内核。
- 移除首次启动前重复的配置解析，增加启动阶段耗时记录，并按实际管理者打开日志目录。

### 升级提示

本版使用宿主与服务协议 v4，必须使用完整安装包同步更新；只更新内核无法取得上述客户端修复。

## 0.2.9

- 新增 Windows 内核独立更新，桌面版本不变时也能跟随本仓库正式内核。
- 支持 YAML 中的 `core-auto-update` 与 `core-update-interval`，在桌面程序运行期间调度；默认不开启自动更新。
- 下载期间保留当前内核，校验完成后替换；启动失败尝试回滚，取消和停止后不会被迟到结果重新启动。

### 升级提示

本版使用服务协议 v3，请先使用完整安装包升级。安装版独立更新内核需要新版桌面服务，即使未开启 TUN；替换运行中的内核会中断已有连接。

## 0.2.8

- 补齐界面、后台和 Windows 服务的启停请求、进程退出结果与关联编号，帮助排查自动停止或恢复的来源。
- 自动记录只读网络状态变化，并合并重复通知；日志异步写入并轮转。
- 本版只补充桌面诊断，未修改内核代码或 TUN 恢复策略，不代表特定 Wi-Fi 故障已经修复。

## 0.2.7

- 遇到明确的旧 TUN 名称冲突时，确认旧内核退出后，自动使用稳定名称 `MihomoDesktop` 恢复一次。
- 原 YAML 保持原样，运行名称映射随原设备名保存，并在设置页显示。
- 保留停止优先级；专属名称仍冲突时明确报错，不删除或接管外部网卡。

## 0.2.6

- 普通断网或 Wi-Fi 切换时保留内核与 TUN，缺失的自有地址和路由优先原地修复。
- 分离服务状态、心跳和串行启停工作，资源等待与恢复期间仍可读取状态和停止。
- 区分进程、控制通道、TUN 健康和当前操作；旧任务不能覆盖新的停止指令。

### 升级提示

服务协议有变化，请用完整安装包同步更新各组件。无法确认归属的旧同名网卡仍会报冲突；本版自动化验证不代替真实 Wi-Fi 和睡眠硬件测试。

## 0.2.5

- 睡眠恢复后重新核对进程和 TUN 实际状态，健康实例保留，局部资源失效优先修复；手动停止优先。
- EasyTier 业务拨号恢复原有 5 秒期限，改为仅对局域网目标后台预连接，覆盖多种内置组网协议。
- 新增可选的代理目标 IP 与地址族策略，保留规则和日志中的域名及 `normal` 模式。

### 升级提示

未知冷目标首次连接仍可能超时；睡眠恢复效果仍需在实际设备验证。

## 0.2.4

- EasyTier 首次组网准备与 TCP 建连分别计时，并按实际目标路由判断就绪；修复并发启动时遗漏状态通知。
- 按显示器工作区和 DPI 调整首次窗口位置，避免高缩放或较矮屏幕上标题栏越界。
- 配置保存成功改为短提示，关闭编辑器或离开页面后清理旧状态。

## 0.2.3

- 更新 Fluent 彩色图标、主页状态卡、快捷开关和选中反馈，改善深色模式对比度。
- 调整状态过渡、等宽数字和卡片响应式布局，窄列连接链保留出口及完整提示。
- 新动效继续遵循系统减少动画和高对比度设置。

## 0.2.2

- 修复返回、导航展开/收起、最小化和关闭按钮首次显示时不能响应鼠标的问题。
- 保留标题栏拖动、双击最大化和 Windows 贴靠；新增真实鼠标输入验收。

## 0.2.1

- 按 Fluent 原稿校准页面布局、字体、背景与边框。
- 调整标题栏搜索、设置控件、连接详情和配置导入/编辑页面。
- 补齐浮层模糊与页面、导航和控件动画，并遵循系统减少动画设置。

## 0.2.0

- Windows 界面迁移到 C# WPF 原生控件与 Fluent 主题，包含完整 .NET 运行环境，无需 WebView2。
- 提供原生搜索、代理拓扑、连接/DNS/规则/日志页面及 YAML 编辑器。
- 接入托盘、系统代理、TUN、配置保护和应用更新等现有后台能力。

### 升级提示

从旧版升级请使用完整安装包，保留原配置目录；不要混用旧版界面和后台程序。

## 0.1.7

- 自动回收应用更新留下的安装包、构建证明和监护程序缓存，兼容早期版本遗留目录。
- 下载、安装或文件占用期间保留缓存，占用解除后重试；崩溃留下的缓存下次启动继续处理。
- 只清理程序可识别的更新目录，不处理手动下载、用户配置或含未知文件/链接的目录。

## 0.1.6

- 修复首次自动启动时，配置检查和资源下载阻塞界面状态读取的问题。
- 在原有期限内继续确认暂时的本地就绪请求失败，认证和监听均确认后才接管系统代理。
- 修复减少动画模式下来源数量和速率标签短暂隐藏，并增加冷资源自动启动验收。

## 0.1.5

- 启动资源下载可使用已有代理组，支持选择、自动测速、故障转移、负载均衡及嵌套组。
- 按原组策略在同一请求预算内处理失败，空组或候选耗尽时不会静默直连。
- 修复服务状态短暂读取失败后，恢复内核却遗漏系统代理偏好的问题。

## 0.1.4

- 新增启动资源引导下载，可用已有静态节点或订阅本地内容取得缺少的规则和 Geo 数据。
- 配置检查、启动、恢复与清理共享有界预算；整理配置、启停和更新入口。
- 应用启动检查遇到繁忙时保留待检查状态，操作结束后继续执行。

## 0.1.3

- 新增每次启动后的后台应用更新检查和可关闭的新版本提示。
- 检查失败不影响代理；只有用户选择安装后才下载并启动安装程序，便携版打开对应发行页。

### 升级提示

0.1.2 及更早版本需先手动检查更新或下载安装包，升级后才具备启动后台检查。

## 0.1.2

- 修复“先卸载再安装”后提示 `Unable to stop the Mihomo desktop service` 的问题。
- 安装器直接查询和停止 Windows 服务，等待旧助手解除占用；卸载会确认服务和助手清理完成，并保留用户配置。

### 升级提示

旧版升级在此错误处中断时，可退出旧程序后直接重试本版完整安装包，无需删除配置。先卸载再安装后，首次启用 TUN 需重新批准服务安装。

## 0.1.1

- 修复普通权限启动界面后，开启 TUN 报“无法验证服务进程，系统错误：5”的问题。
- 服务仅向登记用户授予查询身份需要的有限权限，继续核验界面与服务身份。

### 升级提示

从 0.1.0 升级须使用完整安装包替换旧服务。先卸载再安装后，首次启用 TUN 需重新批准服务安装。
